# OpenHydroNet 诊断要点

对照表：

| 现象 | 优先检查 | 不要先做 |
|---|---|---|
| 全时段技能为负 | 特征、单位、标准化、时间对齐 | 盲目加训练轮次 |
| 总量偏湿/偏旱 | 目标变换、损失权重、强迫偏差 | 套用 XAJ 蒸散发叙事 |
| 峰现滞后/提前 | 序列长度、记忆机制、事件分割 | 用概念性汇流参数解释 |
| 仅某流域差 | 空间外推与训练分布 | 宣称通用收敛 |

检查清单：

- [ ] 推理配置与训练配置一致（窗口、特征集、归一化）
- [ ] 校准/检验分区未泄漏
- [ ] 有可对比的简单基线（持久性或概念模型）
- [ ] 实验登记了否证条件

反例：把 `routing` 参数组写进 OpenHydroNet 实验计划。
