# 汇流诊断

汇流实验主要观察时序与形态是否按假设方向变化：峰现、峰顶平滑程度、过程宽度及洪水尾部。

## 指标对照

| 现象 | 优先假设 | 否证信号 |
|---|---|---|
| 峰现系统性提前/滞后 | 汇流记忆或河网滞时 | 改 routing 后总量大幅漂移 |
| 总量接近但过程过尖/过钝 | 调蓄与退水参数 | 只改善一场、其余事件退化 |
| 退水过快或过慢 | 基流/地下水出流记忆 | 洪峰相位不变、仅尾部抖动 |

## 检查清单

- [ ] 水量大致合理后再动 routing
- [ ] 记录峰现时差与过程宽度，不只看 NSE
- [ ] 局部触边界 ≠ 可无限扩大绝对边界
- [ ] 多事件对照，避免单场过拟合

若改变 routing 组只能改善某一事件却让其他事件明显退化，应降低该假设优先级，而不是继续放宽边界。
