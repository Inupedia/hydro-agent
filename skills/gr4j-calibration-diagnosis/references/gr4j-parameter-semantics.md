# GR4J 参数语义（诊断用）

本参考描述 Hydro-Agent 当前 NumPy 实现。公式对齐 Perrin et al. (2003)，并已与 airGR 对齐参考（GRsuite / airGR 1.7.9）完成逐日状态与流量 parity；正式自动率定已开放。

| 组 | 参数 | 主要现象 |
| --- | --- | --- |
| production | X1 | 长期水量偏差、蒸散发调节不足 |
| exchange | X2 | 基流偏高/偏低、水量闭合误差 |
| routing | X3, X4 | 洪峰相位、退水过快/过慢 |

实现边界：日尺度集总、无雪过程；气温/积雪/冻融不得用 GR4J 参数解释。不要输出连续参数向量；只建议参数组与策略方向。
