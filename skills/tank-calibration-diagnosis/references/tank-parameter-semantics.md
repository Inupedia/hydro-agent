# 三层 Tank + Nash 参数语义（诊断用）

当前结构只有一个表层阈值 `H1`：`A11` 作用于超过阈值的侧向出流，`A12` 作用于全部表层蓄量；不要把二者描述成两个都有独立孔高的标准 Tank 出口。`N` 在 Core 中取整为离散级数（1–5），不得当作连续物理量解释。

| 组 | 参数 | 主要现象 |
| --- | --- | --- |
| surface | H1, A11, A12, B1 | 阈值侧向洪峰、表层出流过快、向下层补给不足 |
| intermediate | H2, A2, B2 | 壤中流、次洪峰、向深层补给 |
| base | A3 | 基流偏高/偏低 |
| routing | K, N | 洪峰相位、过程线展宽（N 离散） |

不要输出连续参数向量；只建议参数组与策略方向。
