# 水文实验报告

报告按资料/模型/目标/预算与 seed、校准/开发/封存测试窗口、基线与候选及采纳方案、完整过程线、多指标、Gate、停止原因和限制组织。明确 `BUDGET_EXHAUSTED`、未达标、回滚与真正收敛的区别，引用每项结论的 Evidence/Artifact ID。

本 Skill 不重新计算指标、不改锁定规则、不以未采纳的候选方案冒充最终方案，也不把开发期测试称为独立 final-test。
