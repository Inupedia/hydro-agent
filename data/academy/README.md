# Bundled Yaogu academy data

Copied from `xaj-offline-reusable-20260908-v6/academy/examples`.

This is the only basin currently used by the workbench. Modeling and
hydrologist calibration read `examples/data` and `examples/dem/yaogu`
from this directory. Keep both the unpacked `.hgt` tiles and the original
`.hgt.gz` payloads listed in `sources.json`; the teacher delineator archives
the gzip files with each case. Do not re-download Skadi tiles.
