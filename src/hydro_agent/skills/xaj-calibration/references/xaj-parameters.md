# XAJ 参数说明（蒸馏）

来源：教学/实现参数说明与 `parameter_bounds.yaml`。率定时优先动 `calibrate: true` 的参数。

## 参数表

| 模块 | 参数 | 含义 | 推荐范围 | 对径流的作用 |
|---|---|---|---|---|
| 蒸散发 | KC / K | 蒸散发能力折算 | [0.50, 1.50] | 增大→蒸发↑、径流↓ |
| 蒸散发 | WUM / UM | 上层张力水容量 | [5, 35] mm | 增大→初期产流延缓 |
| 蒸散发 | WLM / LM | 下层张力水容量 | [40, 100] mm | 增强干旱缓冲 |
| 蒸散发 | WDM / DM | 深层张力水容量 | 由 WM−WUM−WLM | 非独立输入列 |
| 蒸散发 | C | 深层蒸散发系数 | [0.08, 0.25] | 增大→枯水消耗加快 |
| 产流 | IMP / IM | 不透水面积比 | [0, 0.10] | 增大→洪峰更高更早 |
| 产流 | WM | 总张力水蓄水容量 | [80, 220] mm | 增大→蓄满更难、洪峰↓ |
| 产流 | B | 蓄水容量曲线指数 | [0.1, 0.5] | 增大→更早局部蓄满 |
| 水源 | SM | 自由水蓄水容量 | [5, 55] mm | 增大→洪峰推迟、过程更缓 |
| 水源 | EX | 自由水容量曲线指数 | [0.8, 2.0] | 增大→地表径流占比↑ |
| 水源 | KI | 壤中流出流系数（日） | [0.08, 0.55] | 增大→壤中流更快 |
| 水源 | KG | 地下径流出流系数（日） | [0.08, 0.50] | 增大→地下补给更快 |
| 汇流 | CI | 壤中流消退 | [0.55, 0.95] | 增大→记忆更强、退水慢 |
| 汇流 | CG | 地下径流消退 | [0.90, 0.995] | 增大→基流更长 |
| 汇流 | CS | 河网消退 | [0.20, 0.90] | 增大→洪峰降低滞后 |
| 汇流 | LAG / L | 纯滞后时段 | [0, 6] | 整数；过程后移 |

## 实现约束

1. `WDM = WM - WUM - WLM`（不单独输入）
2. `KG`、`KI`、`CG`、`CI` 按日尺度输入；亚日运行时程序换算；`CS` 按模型时段
3. **必须** `KG + KI < 1`
4. `LAG` 取整；小数部分不形成分数时段滞后

## 有界率定常用分组

- `evap`: K, UM, LM, DM, C
- `runoff`: B, IM, SM, EX, KI, KG
- `routing`: CS, CI, CG, L
