# XAJ 产流形成诊断

关注降雨输入与径流响应之间的非线性关系：小雨响应、强降雨放大、土壤蓄水状态依赖和事件总径流。

## 指标对照

| 现象 | 优先假设 | 否证信号 |
|---|---|---|
| 总量合理但洪峰偏弱/偏强 | 产流能力或蓄水阈值异常 | 改 runoff 后总量明显恶化 |
| 小雨几乎无响应、大雨过冲 | 产流非线性/阈值偏高 | 湿润期与干旱期响应方向不一致 |
| 事件总量差、过程形状尚可 | 水源划分或初损问题 | 仅某一类事件改善、其他退化 |

## 检查清单

- [ ] 先确认 PBIAS / 总径流不主导，再谈产流形态
- [ ] 比较干旱期与湿润期事件，而不是只看一场洪水
- [ ] 登记开放参数组与否证条件后再跑 A05
- [ ] 不用汇流参数去“修”总量

反例：把某个 NSE 值机械映射成 WM/B；在水量失衡时优先精调产流形状。
