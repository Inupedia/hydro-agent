# 演示默认配置实测

本配置用于现场演示，经过开发期筛选，不作为未经选择的正式研究样本。没有修改原始 XAJ 参数、物理内核或 Gate 阈值。

## 默认配置

- 流域：腰古（`yaogu`）；XAJ 单元集总模型。
- 建模：365 天预热、90 m DEM、50 km² 河网及单元阈值，与页面建模默认一致。
- 日期：2000-04-01 至 2000-08-31；实测日资料模式 R。
- 开发期和最终检验期各 30 天；最多 30 次 Agent 决策、4 次优化。
- Campaign 为连通验证（smoke），声明模型评估预算 800；本次实际 827 次，在第二轮结束后停止。当前 Campaign 是实验间停止阈值，并非能中途截断优化器的全局硬上限。页面「运行设置」可查看或改写停止策略与预算。
- 页面配置权威：`web/src/demo/preset.ts`。腰古任务窗可点击「载入演示默认值」；不会覆盖已有任务，也不会改写已绑定且仍属腰古的模型方案。
- 绑定已就绪方案时，只要日期仍落在资料范围内就不会被改回建模建议短窗口。日期早于建议起点或晚于资料终点时才会回退到方案建议窗。

## 开发期比较

| 配置 | Gate 顺序 | 最终选中方案的开发期 NSE |
|---|---|---:|
| 建模建议短窗口 | ROLLBACK → ROLLBACK | -1.3173 |
| 1991 年 1 月 | ACCEPT → ACCEPT | -38.5670 |
| 1991-04-01 至 1991-08-31 | ACCEPT → ROLLBACK | 0.6057 |
| **2000-04-01 至 2000-08-31** | **ACCEPT → ACCEPT** | **0.4158** |

现场演示优先选择全部候选均获采纳的配置，再比较开发期 NSE。因此选择 2000 年，而非开发期 NSE 最高但末轮回滚的 1991 年。它是本次候选集合中适合演示的选择，不是全局最优参数或跨流域最优默认值。

2000 年配置的开发期 NSE：-1.3235 → -0.0737 → 0.4158；率定期 NSE：-0.7368 → 0.4288 → 0.8323。两次候选参数均被采用，但 Qualification 仍为 UNQUALIFIED；ACCEPT 不等于发布合格。

## 冻结后检验

选定 2000 年配置之后执行冻结、30 次历史起报回放和一次最终报告：

- 连续模拟：NSE 0.8263，KGE 0.8800，PBIAS -9.75%，RMSE 10.5331 m³/s。
- 滚动预报：NSE 0.8397，KGE 0.8903。
- 停止原因：BUDGET_EXHAUSTED；没有宣称收敛或发布合格。

筛选程序最初按开发期 NSE 为 1991 年任务完成过研究收尾，随后根据演示需求改为“全部 Gate 接受优先”，选择 2000 年。此调整依据开发期记录，不依据最终检验分数；两个任务各自的最终检验均只消费一次。相关窗口已经用于演示筛选，不应再冒充正式研究的全新 holdout。

## 复现与证据

```sh
uv run --frozen python scripts/select_demo_preset.py --out artifacts/new-demo-selection
```

输出目录必须不存在，避免覆盖历史记录。程序只在各候选完成 Gate/Resolve 后比较开发期证据，并对选中的演示任务做最终检验。

本次原始记录：`artifacts/demo-preset-verified/selection.json`；默认选择：`artifacts/demo-preset-verified/demo-default.json`；最终报告目录：`artifacts/demo-preset-verified/reports/task-dbffdf3f5ce4/`。这些本地运行产物不纳入 Git。

本次使用确定性 calibration-scientist 决策策略和真实 DEM/XAJ/优化/Gate 服务，没有调用收费 LLM。生产入口若使用实时 LLM，策略选择可能不同，不能保证每轮复现相同分数或全部 ACCEPT。原始模型参数保留不变，不把已率定参数预填为基线来伪造改进。
